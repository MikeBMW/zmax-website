全链路数据质量管理策略 · 五维时空打标 · 六步闭环

全局数据空间 = 54 种条件场景（输入）→ 5 个专用模型（推理）→ 48 种原子动作（输出）→ 4 款机器人（执行）→ 数据回灌训练（进化）

一、全局数据空间的核心架构

1.1 设计哲学：条件驱动，非任务编程

Z-MAX 不做通用大模型，而是把产线拆解为 54 种条件场景，每种条件映射到最优的专用小模型，输出 48 种原子动作，由 4 款机器人执行。

1.2 五大设计原则

条件驱动非任务编程，由传感器条件触发推理
多模型池非单一通用模型，54条件→5模型池
原子技能组合非端到端黑箱，242条原子技能可组合
数据闭环自进化执行结果回灌训练，持续迭代
边缘-云端协同Sys1(<5ms) + Sys2(~280ms) 分层推理

3.4 数据质量门禁

🚪 采集门禁
单次采集≥300帧，传感器数据完整
不达标 → 重新采集
🚪 标注门禁
标注一致性≥95%，质检抽样通过
不达标 → 退回重标
🚪 训练门禁
训练集分布与验证集无显著偏移
不达标 → 扩充数据
🚪 部署门禁
新模型在验证集成功率≥当前模型
不达标 → 拒绝部署

四、策略总结

54条件场景（输入）
5专用模型（推理）
48原子动作（输出）
4款机器人（执行）

一条主线：条件驱动 · 数据闭环 · 持续进化
两个引擎：左侧控制流程 + 右侧质量监督
三个层级：系统0(执行) → 系统1(推理) → 系统2(训练)
四个核心：54条件 + 5模型 + 48动作 + 4机器人
五个维度：X·Y·Z 空间 + T 时间 + S 语义(感知/特征/条件/动作/反馈)
六步闭环：采集 → 标注 → 训练 → 部署 → 执行 → 回灌

以 5 维时空打标（X·Y·Z·T·S）为数据质量管理基准，形成 感知→推理→执行→反馈 的完整闭环。
