1. 定位与范围

项说明
产线型号800G DR8 (料号: 260-B4103) · 72步完整工艺
OE工位26 站（1~26），覆盖来料准备→LD AA耦合→TRX FA组装
物料载体料笼（连板panel载体） 料盘（模块载体） Tray盘（热工艺工装）
机器人配置Z100L 料笼搬运 + Z100L AOI目检 + Z100L上下料 · 自动设备工位不配机器人
核心工艺DA1~DA4贴片 → WB金线键合(193根) → PEI Cover → 隔离器 → 激光分板 → LD AA耦合
OE区是800G DR8光引擎制造核心工艺段。采用COC(chip-on-carrier)工艺，经4次DA贴片、WB金线键合、Cover封装、隔离器安装、激光分板、LD Lens AA耦合。机器人配置原则：目检工位 Z100L AOI，上下料工位 Z100L，料笼工位 Z100L搬运，自动设备工位不配机器人。

2. 工序流程总览

工序流程总览（26工位 · 8大阶段）

【来料准备段 1~3】物料准备 → 进料检验&贴标签 → FW烧录/IPSN写入 【热沉段 4~7】Plasma清洗热沉 → 热沉点胶 → 热沉贴装&固化 → 热沉烘烤+目检 【DA1段 8~11】DA来料目检 → DA1垫块贴装 → DA1二次元&目检 → DA烘烤-1+目检 【DA2段 12~15】DA2芯片贴装 → COC SN绑定 → DA2二次元&目检 → DA烘烤-2+目检 【DA3段 16~17】DA3芯片贴装 → DA3二次元&烘烤+目检 【WB+封装段 18~20】Plasma-WB+WB键合&目检 → PEI Cover组装+烘烤+目检 → 隔离器贴装+烘烤+目检 【DA4+分板段 21~23】DA4芯片+红外测量 → DA4二次元&烘烤+目检 → 激光分板+保护治具 【耦合段 24~26】Plasma-LD+耦合前目检 → LD Lens AA耦合 → Mpd_test+TRX FA组装
