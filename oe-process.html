1. 定位与范围

项说明
产线型号800G DR8 (料号: 260-B4103) · 72步完整工艺流程
OE工位数量26 站（1~26），覆盖 OE-前段 42步和 OE-后段核心工序
物料载体料笼（料盘载体） 料盘（模块载体） Tray盘（热工艺工装载体）
操作人数约 46 人（DA贴片/耦合/WB/组装等）
物料流转连板(panel)经料笼在工位间流转，工位内料盘/Tray盘传递
前段工艺物料准备 → Plasma清洗 → DA1~DA4贴片 → WB金线键合 → PEI Cover → 隔离器 → 激光分板
后段工艺(部分)LD Lens AA耦合 → Mpd测试 → TRX FA组装/清洁 → TRX FA AA耦合(后段详见MOD区)
OE区是800G DR8光引擎制造的核心工艺段。采用COC(chip-on-carrier)工艺路线，经过4次DA贴片(PIC/TIA/PD/COC/FD Lens等)、WB金线键合(193根金线)、PEI Cover封装、隔离器安装、激光分板等关键工序。前段42步覆盖从物料准备到LD耦合前目检，后段23步覆盖AA耦合到出货检查。

2. 工序流程总览

工序流程总览（26工位 · 8大阶段）

【来料准备段】物料准备 → Plasma清洗 → 进料检验贴标 → FW烧录/IPSN写入 【热沉段】Plasma清洗热沉(24h) → 热沉点胶 → 热沉贴装&固化 → 热沉烘烤+目检 【DA1段】DA来料目检 → DA1垫块贴装 → DA1二次元+目检 → DA烘烤-1+目检 【DA2段】DA2芯片贴装 → COC SN绑定+DA2二次元 → DA烘烤-2+目检 【DA3段】DA3芯片贴装 → DA3二次元+烘烤+目检 【WB+封装段】Plasma-WB+WB键合 → PEI Cover组装+烘烤 → 隔离器贴装+烘烤 【DA4+分板段】DA4芯片+红外测量 → DA4二次元+烘烤+目检 → 激光分板+保护治具 【耦合前段】Plasma-LD+耦合前目检 → LD Lens AA耦合(6台并行) → Mpd_test+TRX FA

从线边仓接收COC来料(连板panel形式)，完成物料清点、Plasma清洗、进料检验及FW烧录。
